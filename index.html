    מראה

    תדריך אוטומטי

    התוכנה מכינה את תדריך הבוקר בעצמה, בפתיחה הראשונה של כל יום. היא מחפשת את החדשות, קוראת את הדירוגים והבקשות שלך, וכותבת תדריך חדש. לשם כך נדרש מפתח API של Anthropic, פעם אחת בלבד.

    המפתח נשמר רק בדפדפן של המכשיר הזה ואינו נכלל בקובץ הגיבוי. כל מי שמשתמש בדפדפן הזה יכול להשתמש בו, ולכן מומלץ להגדיר תקרת הוצאה חודשית ב-Claude Console.

    קול ההקראה באנגלית

    כברירת מחדל נבחר אוטומטית הקול הנשי האיכותי ביותר שמותקן במכשיר. אפשר לבחור קול אחר מהרשימה.

    הקולות תלויים במכשיר. באייפון אפשר להוריד קולות נשיים איכותיים, כמו Ava או Samantha בגרסת Premium או Enhanced, דרך הגדרות › נגישות › תוכן מוקרא › קולות › English. באנדרואיד מוסיפים קולות בהגדרות המכשיר, תחת "המרת טקסט לדיבור". אחרי ההורדה, פתח מחדש את האפליקציה ובחר את הקול כאן.

    גיבוי ושחזור

    כל ההתקדמות שלך נשמרת בדפדפן של המכשיר הזה בלבד. גבה אותה מדי פעם, ושחזר אותה כשאתה עובר למכשיר או לדפדפן אחר.

    ייבוא ידני של תדריך

    אינו נדרש כשהתדריך האוטומטי פעיל. אם קיבלת בלוק תדריך, הדבק אותו כאן ולחץ "ייבא תדריך". ההתקדמות שלך בפריטים קיימים נשמרת.

    בקשות פתוחות

    בלי תדריך אוטומטי, העתק את בקשות "תלמד אותי על..." ושלח אותן יחד עם הבקשה לתדריך הבא.
